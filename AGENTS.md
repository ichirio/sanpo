# Agent / contributor instructions for sanpo

This repository **is the R package** (`DESCRIPTION` is at the root). This is
a short orientation; `CONTRIBUTING.md` has the workflow.

## Invariants -- do not break

- **Static `ggplot2` only.** Plot functions return an ordinary `ggplot`; no
  htmlwidgets.
- **Three layers per figure.** `sp_<fig>_data()` (patient-level data ->
  small summary table), `sp_plot_<fig>()` (summary table -> `ggplot`) and
  the one-call `sp_<fig>()` that only chains the two. No hidden steps.
- **Light dependencies.** `Imports:` stays within `ggplot2`, `dplyr`,
  `rlang`, `tidyr` (plus base packages and `survival`); everything else is
  in `Suggests:` and reached through `requireNamespace()`.
- **Column names are passed as strings** (`id = "patient_id"`).
- **English labels by default** (`lang = "en"`).
- **ASCII-only R code** (use `\uXXXX` escapes for Japanese text).
- **No real data.** Examples and tests use made-up data such as
  `sp_synth_pathways()`.
- **`NAMESPACE` and `man/` are generated by roxygen2**; commit them.

## Workflow

1. One issue -> one branch off `main` -> one pull request.
2. Change `R/`, `tests/testthat/` and the roxygen docs together.
3. Run `roxygen2::roxygenise()`, `testthat` tests, `R CMD check --as-cran`
   and `lintr::lint_package()` (target: 0 errors / 0 warnings / 0 lints).
4. Bump the **fourth** version number in `DESCRIPTION` (`0.0.0.9000` ->
   `0.0.0.9001`) and add a line to `NEWS.md`.
5. Open the pull request against `main`.

## Layout

```
R/  man/  tests/testthat/  .github/workflows/
DESCRIPTION  NAMESPACE  NEWS.md  README.md  LICENSE.md
```
